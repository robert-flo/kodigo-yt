# 01: La puerta yt descarga un audio

**What to build:** Quien ejecuta `yt` en una terminal ve el banner y el menú. Elige audio, pega una URL y corre la descarga de audio que ya existía. `yt audio <url>` hace lo mismo sin menú. Sin terminal, `yt` muestra el help. Un comando desconocido falla.

**Blocked by:** None (can start immediately).

**Status:** hecho en esta entrega

- [x] El menú ofrece audio como primera opción y sale con `q`
- [x] `yt help` lista los comandos
- [x] `yt audio` sin URL muestra la ayuda del módulo original
- [x] `yt no-existe` termina con error
